# A2B 寄存器分析看板

[在线查看 GitHub Pages](https://jerrylianjian.github.io/a2b-register-analyzer/)

## 中断统计

网页默认显示「第二次实测汇总」，从 2026-11-25 20:00（按日志的 `Compile Start`）起统计，早于该时点的记录不合并进本次汇总。可按时间、链路、节点、寄存器和读取范围筛选，并导出 CSV。

- `0x73`、`0x2D`、`0x2F` 以非零读回为命中；`0x2E` 仅以 `0x01` 为命中。主节点不受 `0x12` 限制。
- 从节点实际读取的四个寄存器均可统计，但同一轮、同一链路、同次选址内的 `0x12` 须成功读回 `0x13`。不同选址或轮次的 `0x12` 不互用；缺失、失败或读回非 `0x13` 时排除。`—` 表示没有通过校验的有效读回，不等于 0 次。
- 针对本脚本格式自动识别链路：偶地址为主设备，下一个地址为从节点访问地址。从 1–10 由主地址上成功写入的 `0x18` 确定，不限制组数。每条符合条件的有效读回算 1 次；同一节点和寄存器还显示同轮去重后的命中轮次。两者都不等于物理中断次数。
- 网页只公开本次逐轮汇总计数及轮次时间，不含原始日志、文件名、路径、寄存器原始读值或逐次读回。本地导入不上传。

## 中断与箱温时序

「中断统计」上方显示采样范围、首次/末次命中的轮次时间及箱温估算范围。图中柱形为各轮的寄存器命中读回，绿色曲线为估算箱温，两者用同一时间轴。悬停、点击或键盘选中一个时间点可看详情。「查看逐轮数据」和「导出逐轮 CSV」提供每轮时间、命中次数和箱温；汇总 CSV 另带每个节点/寄存器的首末命中时间及对应估温。

第二次日志没有实测箱温。点「设置温度基准」，按下方程序录入一个阶段开始时间，或已知的终点温度和阶段，再显示估算曲线。未设置基准、或在基准范围以外的轮次，温度留空。

## 读值历史与首现

「上次实测历史」保留 70 个日志的历史：41,555 次有效读回（含零值、非零和重复值），以及 877 条可归属但失败或缺值的读取；另有 858 条选址上下文不足的读命令未计入。上次公开数据没有从节点 `0x12`，不补算该批从节点中断；首现仍按上次原口径展示。

- 读值历史保留未通过中断筛选的原始读回并标注统计状态。新导入日志的节点矩阵和时间轴使用中断筛选口径。
- 「只看 → 回到零」显示上一次有效读回为非零、本次为 0x00 的记录；失败或缺值不被视为 0x00。
- 「读值历史 → 导出 CSV」导出当前筛选条件下的所有匹配记录，而不只是当前页。节点矩阵和首现时间轴仍可使用。
- first-occurrence.json 保留首现汇总；read-history.json 保存逐轮读回数据。两个文件均不含原始日志、文件名或行号。node=0 为主节点，invalid_reason 为 0 表示有效读回，1/2/3 分别表示命令失败、无配套读回值、无效格式或读回起始地址不符。
- 时间取日志的 Compile Start，不代表寄存器实际变化时刻。同轮序号只表示日志记录顺序。
- 可导入新的 Script 执行日志；解析在浏览器内完成，文件不上传。

## 温度估算

在「温度估算（温箱程序）」选择已知阶段，并填写该阶段开始时刻（与 Script 日志同一时钟）。高/低温各保持 90 分钟（105 ℃ / −40 ℃），升降温各按 4 ℃/分钟。单程 36 分 15 秒，完整循环 4 小时 12 分 30 秒。可指定截止时间来避免越过暂停或重启。

「读值历史」和 CSV 会带上估算箱温与阶段，首现详情和首现 CSV 同步支持估算。温度是程序设定曲线按轮次开始时间反推的估算值，不是实测温度；未设置基准或超出给定区间时留空。导入另一批数据、恢复汇总或刷新时清除温度基准。算法单独保存在 temperature-profile.js。

### 从终值倒推

在温度估算中选择「从终值温度往前倒推」，输入终点的日志时间、箱温和升降温方向。若终点在 105 ℃ 或 −40 ℃ 保温段，还要输入该刻已经保温了多少分钟。可选填「最早估算时间」，避免跨过程序暂停或重启。只计算终点及之前，不外推到终点之后。

节点矩阵显示每个首现的估算箱温与温度阶段。首现时间轴在同一横轴上显示估算温度曲线；首现标记可查看该时刻的温度。未设时间基准时不绘制温度。

## 本地复核

`node --test tests/interrupts.test.cjs` 检查多链路识别、值过滤、失败/缺值、选址隔离和时间范围。重新生成公开汇总时运行 `node scripts/generate-interrupt-summary.cjs <本地日志目录> "2026-11-25 20:00:00"`；它只替换网页内的汇总数据块。
